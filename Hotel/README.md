# Gestion Hotelera - Avance de Práctica de Campo

Proyecto Java desarrollado en Eclipse para evidenciar:

- Programación Orientada a Objetos.
- Sobrecarga de métodos.
- Manejo de errores.
- Colecciones ArrayList.
- Uso de Git y GitHub.
- Consideración futura de MySQL mediante JDBC.

## Archivos principales

- Habitacion.java
- Cliente.java
- Reserva.java
- Caja.java
- Hotel.java
- Main.java

## Base de datos

La versión actual trabaja con ArrayList. La carpeta `sql` incluye un diseño preliminar MySQL para futuras etapas del proyecto.
