# HotelPro PC5 - Sistema de Gestión Hotelera

Proyecto Java para la Práctica de Campo.

## Incluye

- Diagrama de clases propuesto en documentación.
- Manejo de archivos en Java mediante FileWriter, BufferedWriter, FileReader y BufferedReader.
- Implementación de requerimientos funcionales principales.
- Evidencia de Programación Orientada a Objetos.
- Clases: Hotel, Habitacion, Cliente, Reserva, Caja, MovimientoCaja, ArchivoUtil, Main.
- Carpeta `data` para archivos generados por el programa.
- Carpeta `sql` con diseño preliminar MySQL para futuras etapas.

## Ejecución

Abrir el proyecto en Eclipse y ejecutar `Main.java`.

El sistema puede guardar y leer clientes desde:
