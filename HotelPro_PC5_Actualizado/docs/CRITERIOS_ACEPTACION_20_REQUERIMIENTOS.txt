CRITERIOS DE ACEPTACION - 20 REQUERIMIENTOS IMPLEMENTADOS

RF01 Registrar habitaciones.
- El sistema debe permitir crear habitaciones con número, tipo, precio y estado.
- Las habitaciones deben quedar disponibles para consulta.

RF02 Consultar habitaciones.
- El sistema debe mostrar el listado general de habitaciones.
- Debe visualizar número, tipo, precio y estado.

RF04 Cambiar estado de habitaciones.
- El sistema debe permitir cambiar el estado de una habitación existente.
- Debe mostrar mensaje de confirmación.

RF05 Registrar clientes.
- Debe registrar DNI, nombres, apellidos y teléfono.
- No debe permitir clientes duplicados por DNI.
- Debe mostrar mensaje de confirmación.

RF06 Consultar clientes.
- Debe mostrar la lista de clientes registrados.
- Si no existen clientes, debe indicarlo.

RF07 Modificar clientes.
- Debe permitir actualizar nombres, apellidos y teléfono.
- Debe buscar al cliente mediante DNI.

RF08 Eliminar clientes.
- Debe eliminar un cliente mediante DNI.
- Debe mostrar mensaje si el cliente no existe.

RF09 Buscar clientes por DNI.
- Debe retornar el cliente cuando el DNI exista.
- Debe mostrar mensaje cuando no exista.

RF11 Registrar reservas.
- Debe asociar cliente y habitación.
- La habitación debe encontrarse disponible.
- Debe registrar fecha de ingreso y salida.

RF12 Consultar reservas.
- Debe mostrar reservas registradas.
- Si no existen reservas, debe indicarlo.

RF14 Cancelar reservas.
- Debe cancelar una reserva activa.
- Debe liberar la habitación.

RF15 Mostrar habitaciones disponibles.
- Debe filtrar habitaciones en estado Disponible.
- Debe mostrar su información completa.

RF18 Realizar check-in.
- La habitación debe estar reservada.
- Debe cambiar a estado Ocupada.

RF19 Realizar check-out.
- La habitación debe estar ocupada.
- Debe calcular el pago.
- Debe registrar ingreso en caja.
- Debe liberar la habitación.

RF20 Calcular costo de hospedaje.
- Debe multiplicar precio por cantidad de días.
- Debe mostrar el total a pagar.

RF21 Registrar ingresos.
- Debe registrar ingreso por hospedaje al realizar check-out.
- Debe incluir descripción.

RF22 Registrar egresos.
- Debe permitir registrar monto y descripción.
- Debe agregar el movimiento a caja.

RF23 Consultar movimientos de caja.
- Debe listar ingresos y egresos.
- Debe mostrar tipo, monto y descripción.

RF24 Calcular saldo de caja.
- Debe sumar ingresos.
- Debe restar egresos.
- Debe mostrar saldo final.

RF30 Buscar habitaciones por tipo.
- Debe permitir buscar habitaciones por tipo.
- Debe mostrar las habitaciones coincidentes.
